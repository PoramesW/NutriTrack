NutriTrack – คู่มือการใช้งาน

1. การสมัครสมาชิกและเข้าสู่ระบบ (Membership)

1. เปิดเว็บไซต์ NutriTrack
2. เลือกเมนูสมัครสมาชิก (Register) สำหรับผู้ใช้งานใหม่
3. กรอกชื่อ อีเมล และรหัสผ่านตามเงื่อนไขที่ระบบกำหนด
4. กดปุ่มสมัครสมาชิกเพื่อสร้างบัญชี
5. สำหรับผู้ที่มีบัญชีอยู่แล้ว สามารถเข้าสู่ระบบ (Login) ด้วยอีเมลและรหัสผ่าน

2. หน้า Dashboard

ใช้สำหรับดูภาพรวมข้อมูลโภชนาการประจำวัน ประกอบด้วย

- ปริมาณแคลอรีที่ได้รับในวันนั้น
- ปริมาณโปรตีน คาร์โบไฮเดรต และไขมัน
- เปรียบเทียบปริมาณสารอาหารกับเป้าหมายที่กำหนดไว้ หากมีเป้าหมาย
- แสดงน้ำหนักล่าสุดที่บันทึกไว้
- แสดงรายการอาหารที่รับประทานในวันนั้น

ผู้ใช้งานสามารถบันทึกน้ำหนักล่าสุดผ่านส่วนจัดการน้ำหนักบนหน้า Dashboard ได้

3. หน้า Nutrition

ใช้สำหรับคำนวณข้อมูลด้านโภชนาการและพลังงานของร่างกาย

1. เข้าสู่หน้า Nutrition
2. กรอกข้อมูลส่วนบุคคลตามช่องที่ระบบกำหนด เช่น อายุ เพศ น้ำหนัก และส่วนสูง
3. กดปุ่มคำนวณ
4. ระบบจะแสดงผลการคำนวณ ได้แก่
   - BMI: ดัชนีมวลกาย
   - BMR: พลังงานพื้นฐานที่ร่างกายใช้
   - TDEE: พลังงานที่ร่างกายใช้ต่อวันโดยประมาณ
5. ตรวจสอบเป้าหมายพลังงานที่ระบบแนะนำ

4. หน้า Food Tracking

ใช้สำหรับบันทึกอาหารและติดตามปริมาณสารอาหารที่ได้รับ

1. เข้าสู่หน้า Food Tracking
2. เลือกเมนูเพิ่มอาหาร
3. ค้นหาอาหารจาก Food Catalog
4. เลือกรายการอาหารที่ต้องการ
5. ระบุปริมาณอาหารและมื้ออาหาร
6. ตรวจสอบข้อมูลแคลอรี โปรตีน คาร์โบไฮเดรต และไขมัน
7. กดยืนยันเพื่อบันทึกรายการอาหาร

**การลบรายการอาหาร**
- เลือกรายการอาหารที่ต้องการลบ
- กดปุ่มลบรายการ
- ระบบจะนำรายการดังกล่าวออกจากประวัติการรับประทานอาหาร

5. หน้า Analyzation

ใช้สำหรับวิเคราะห์ข้อมูลโภชนาการย้อนหลัง

1. เข้าสู่หน้า Analyzation
2. เลือกช่วงเวลาที่ต้องการวิเคราะห์ เช่น 1 วัน, 7 วัน, 28 วัน, 90 วัน, 365 วัน หรือข้อมูลทั้งหมด
3. ระบบจะแสดงกราฟและสถิติที่เกี่ยวข้อง ได้แก่
   - ปริมาณแคลอรีที่ได้รับ
   - ปริมาณโปรตีน
   - ค่าเฉลี่ยและสถิติการรับประทานอาหาร
   - แนวโน้มการเปลี่ยนแปลงของน้ำหนัก
4. ตรวจสอบข้อมูลเพื่อประเมินพฤติกรรมการรับประทานอาหารของตนเอง

6. การออกจากระบบ (Logout)

1. กดปุ่ม Logout ที่เมนูด้านข้าง
2. ระบบจะออกจากบัญชีผู้ใช้งาน
3. หากต้องการใช้งานอีกครั้ง ให้เข้าสู่ระบบด้วยบัญชีเดิม

---

**หมายเหตุ:** ข้อมูลบน Dashboard และ Analyzation จะแสดงตามประวัติที่ผู้ใช้งานบันทึกไว้ในระบบ หากยังไม่มีข้อมูล ระบบจะแสดงสถานะว่างแทนข้อมูลสาธิต
